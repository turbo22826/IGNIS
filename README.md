价格保护与抗通胀动态机制
本机制为 $IGNIS 经济模型的核心稳定模块，用于对冲市场下行情绪、约束代币通胀、动态调节流通供给，并非刚性价格保底承诺。机制持续读取链上实时市场价格与代币流通数据，以流动性池充足度、流动性占流通比例为前置判定条件，在满足平衡阈值时启动动态铸烧模型，实现铸造越多、销毁越多的通缩对冲效果。

在市场情绪低迷、价格承压阶段，单纯依靠交易销毁不足以对冲新增铸造带来的供给增量。价格保护与抗通胀机制将流动性池规模、流通总量纳入统一校验模型，在保障流动性深度充足、流动性池代币占流通总量维持平衡区间的前提下，将新增铸造行为与销毁动作绑定。每一笔合格铸造触发对应的销毁逻辑，把新增供给同步回收至0x......dead的黑洞地址，以此抵消铸造带来的增量抛压，平抑市场恐慌情绪，维持代币底层稀缺性。

该机制拥有明确的边界条件：只有流动性池充足、流动性代币存量与当前流通总量达到合约预设平衡比例时，动态铸造 - 销毁链路才会激活；若流动性占比低于阈值，该铸烧联动机制自动暂停，优先保障 DEX 交易的流动性深度。

$IGNIS 代币合约硬上限为 44 万亿枚，这是铸造与流动性锁定合计的理论最大总量。依托价格保护、流通锁定与动态销毁机制约束，当全部 400万份铸造完成时，代币实际流通总量将不超过代币设计总流通的5%；在理想销毁节奏下，流通量可以进一步低于该数值。绝大部分代币将通过销毁、流动性锁定的方式永久退出流通市场，大幅压缩可交易代币，持续塑造代币长期通缩基底。

4. 代币经济模型说明
社区高频疑问：持续铸造是否代表无限增发？ 每一次铸造都会生成对应数量的 $IGNIS，这是代币唯一发行途径，同时整套模型内置多重约束与销毁机制对冲通胀。

两道硬上限：

铸造份数上限：4,000,000 份，份数耗尽，铸造合约直接停止铸造.
代币总量上限：44 万亿枚，合约拒绝铸造超出上限的代币,任意一条上限触发，铸造永久停止。最终实际流通量会远低于总量上限，由铸造进度、动态销毁机制、交易销毁共同决定。
新代币去向： 每成功铸造一份，铸造$IGNIS，归属铸造用户；

铸造资金 40% 买入代币配对40% 资金注入 LP 底池，20% 资金进入双多签金库。 铸造带来新增供应，但受多重通缩规则约束：

合约硬顶：份数、代币总量双重上限锁死最大供给。
全额付费铸造：没有免费代币释放，不存在团队解锁、VC 份额释放。
资金沉淀：80% 铸造资金沉淀进流动性池，夯实底池深度。
阶梯涨价：铸造成本持续上行，后期铸造成本高于早期。
双层销毁：买卖交易持续销毁；满足动态销毁与价格保护机制的阈值时周期性无限销毁代币。
熔断保护：开盘后按当前阶梯价格计算未封顶市场报价，每份超过 2000 万枚 IGNIS 时触发熔断保护机制，单份实际铸造数量最多2000万枚IGNIS。批量铸造按份数同比计算熔断阈值，份数*2000万枚IGNIS，熔断机制触发情况下开发团队没有权限人为关闭或开启铸造按钮（用户自行注意风险）。
权限放弃：上线后管理权限放弃，税率、销毁规则、铸造定价规则无法后台篡改
流通量计算规则： 铸造合约 circulating  = 总供应量 − LP 底池内 IGNIS − 黑洞销毁地址代币 − Minter 合约待兑换税费代币。 

铸造、交易、动态销毁机制都会实时改变流通量：铸造增加流通；交易卖出触发销毁、减少流通；价格保护机制与动态销毁直接将底池代币打入黑洞，永久减少流通供给。

LP 动态销毁间隔：LP 底池内当前存量代币 ≥ 当前流通总量 × 40% 时，每满 1 分钟可触发一次燃烧；低于 40% 且 ≥ 15% 时，每满 3 分钟可触发一次燃烧；低于 15% 时暂停。每次将池内 IGNIS 的 0.01% 转入黑洞，不动池内 BNB。间隔按燃烧前的实时占比判断，自上次成功燃烧起计算；需交易或 Keeper 调用触发，不补烧错过的间隔。全部份额铸造完成满 15 天后永久停止 LP 燃烧。
